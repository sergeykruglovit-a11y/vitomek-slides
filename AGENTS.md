# Инструкция для ИИ-агента: сборка презентации VITOMEK

Ты собираешь презентацию в корпоративном шаблоне VITOMEK из **готового содержания**, которое дал пользователь
(текст, документ, тезисы по слайдам). Твоя задача — разложить это содержание по макетам шаблона и собрать
`.pptx` скриптом `build.py`. Не придумывай новых фактов и цифр.

## 1. Подготовка

```bash
# если репозиторий ещё не скачан
git clone --depth 1 https://github.com/sergeykruglovit-a11y/vitomek-slides.git
# или: curl -L -o vs.zip https://github.com/sergeykruglovit-a11y/vitomek-slides/archive/refs/heads/main.zip && unzip vs.zip
cd vitomek-slides
python3 -c "import pptx" 2>/dev/null || pip install python-pptx
python3 build.py --catalog      # макеты, поля и лимиты знаков
```

Если скачать не получается (нет интернета), попроси пользователя прикрепить к чату архив репозитория
(Code → Download ZIP на странице GitHub) и распакуй его.

## 2. Разложи содержание по макетам → `content.json`

Прочитай вывод `--catalog` и подбери макет под каждую мысль:

| Содержание | Макет |
|---|---|
| название, подзаголовок, дата/автор | «Обложка» (всегда первый) |
| переход к новой части | «Раздел» |
| обычный тезис со списком | «Заголовок и текст» |
| сравнение, было/стало | «Две колонки» |
| текст + фото/иллюстрация | «Текст и картинка» |
| ровно 3 параллельных пункта | «Три карточки» |
| 2–4 ключевых показателя | «Цифры» |
| сильная фраза, отзыв | «Цитата / ключевая мысль» |
| таблица | «Только заголовок» + поле `table` |
| финал с контактами | «Спасибо за внимание» (всегда последний) |

Правила:
- Всё содержание пользователя должно попасть в презентацию. Сокращать можно формулировки, но не факты:
  названия, цифры, имена остаются. Не помещается — раздели на два слайда, а не выбрасывай.
- Укладывайся в лимиты знаков из каталога. Пункт списка — одна мысль.
- Не больше трёх слайдов подряд на одном макете. Если пунктов ровно 3 — «Три карточки», если цифры — «Цифры».
- Заметки докладчика из материала клади в `"notes"` слайда. Содержание слайда в заметки не переноси.
- Картинки: если пользователь приложил изображения, укажи путь в поле `"image"` макета «Текст и картинка».

Формат (пример — `examples/content-example.json`):
```json
{"slides": [
  {"layout": "Обложка", "title": "…", "subtitle": "…", "meta": "Октябрь 2026 • Отдел …"},
  {"layout": "Заголовок и текст", "title": "…", "bullets": ["…", {"text": "подпункт", "level": 1}]},
  {"layout": "Три карточки", "title": "…", "cards": [{"title": "…", "text": "…"}, {"title": "…", "text": "…"}, {"title": "…", "text": "…"}]},
  {"layout": "Цифры", "title": "…", "numbers": [{"value": "50 г", "caption": "…"}, {"value": "–37 %", "caption": "…"}]},
  {"layout": "Только заголовок", "title": "…", "table": {"header": ["…", "…"], "rows": [["…", "…"]]}},
  {"layout": "Спасибо за внимание"}
]}
```

## 3. Проверь и собери

```bash
python3 build.py --check content.json                       # ошибки нужно исправить, предупреждения — желательно
python3 build.py content.json -o "<Название>.pptx" --render  # сборка + картинки слайдов, если есть LibreOffice
```
- `ОШИБКА` — исправь `content.json` и запусти снова.
- `ВНИМАНИЕ` / `ПЕРЕПОЛНЕНИЕ` — сократи текст или разбей слайд, пересобери.
- Если доступен `--render`, посмотри `…_preview/contact.jpg` (и отдельные `slide-NN.png`, если что-то подозрительно):
  текст не налезает, всё содержание на месте, слайды не однообразные.
  Особенность превью: оно рендерится через LibreOffice, который рисует подсказки пустых полей макета
  (например, «0» в неиспользованной плитке «Цифр» или «Вставьте рисунок»). В PowerPoint их нет — не исправляй это.

## 4. Отдай результат

- Дай пользователю ссылку на скачивание `.pptx` (и картинку-обзор, если есть).
- Коротко перечисли: сколько слайдов, какие макеты, что сокращено или разбито, что нужно сделать руками
  (вставить фото в «Текст и картинка», если картинки не было; проверить цифры).
- Шрифт шаблона — TT Norms Pro. Если на компьютере пользователя его нет, PowerPoint покажет Arial — по гайдлайну
  VITOMEK это допустимо.
