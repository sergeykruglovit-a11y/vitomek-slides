# VITOMEK · сборка презентаций в корпоративном шаблоне

Репозиторий для ИИ-агентов (ChatGPT, Claude и другие, которые умеют запускать код): агент скачивает его,
раскладывает ваше готовое содержание по макетам шаблона VITOMEK и собирает `.pptx`.

## Как пользоваться (ChatGPT Plus / Claude Pro и выше)

1. Подготовьте содержание презентации: текст, тезисы по слайдам или документ.
2. Откройте новый чат, приложите материалы и напишите:

   > Скачай репозиторий https://github.com/sergeykruglovit-a11y/vitomek-slides и следуй инструкции AGENTS.md:
   > собери презентацию VITOMEK из приложенного содержания.

3. Получите готовый файл `.pptx`. Его можно открыть и поправить в PowerPoint, Google Slides, Р7, МойОфис.

Если агент не может скачать репозиторий: нажмите на этой странице **Code → Download ZIP**, приложите архив к чату
и напишите то же самое.

## Что внутри

| Файл | Зачем |
|---|---|
| `AGENTS.md` | инструкция для ИИ-агента |
| `layouts.json` | макеты шаблона, их поля и лимиты знаков |
| `build.py` | скрипт сборки: проверяет содержание, собирает pptx, делает картинки слайдов |
| `template/vitomek-template.pptx` | корпоративный шаблон VITOMEK (10 макетов) |
| `examples/content-example.json` | пример содержания для всех макетов |

Запуск вручную (нужен Python и `pip install python-pptx`):

```bash
python3 build.py --catalog
python3 build.py examples/content-example.json -o example.pptx --render
```

Шаблон и фирменный стиль принадлежат VITOMEK. Код скрипта — MIT.
